# Contributing

Bug reports, fixes, and small focused features are welcome. For larger
changes, open an issue first so we can agree on the approach.

## Development

```bash
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
cargo bench --bench throughput   # optional, prints timings
```

The decode fixtures in `tests/fixtures/` are generated by
`tests/fixtures/generate.sh` (requires ffmpeg).

Decoding parses untrusted files, so changes to `src/decoder` or
`src/format.rs` should survive a fuzzing run (requires nightly and
`cargo install cargo-fuzz`):

```bash
cargo +nightly fuzz run decode -- -max_total_time=300
cargo +nightly fuzz run pipeline -- -max_total_time=300
```

## Guidelines

- Keep examples and tests runnable without private files. Use synthetic
  audio or small fixtures with a clear license.
- If you change what formats or features the crate supports, update the
  README tables in the same pull request.
- Don't add hard-coded latency assertions to tests; timing belongs in the
  benchmark.
- Add a line to `CHANGELOG.md` under `Unreleased` for user-visible changes.
- If a substantial part of a change was AI-generated, say so in the pull
  request, and make sure you can explain every line of it.
